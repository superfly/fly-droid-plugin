# Fly.io for Factory Droid

This repo packages the shared Fly.io skills for Factory Droid. The source of
shared behavior is `superfly/skills`; this repo owns the native Factory manifest,
MCP connection, distribution docs, sync tooling, and submission artifacts.

- Never hand-edit files listed in `upstream.lock.json`. Change them upstream,
  then run `python3 scripts/sync_shared.py --ref <upstream-commit>`.
- The lock pins an immutable commit and hashes every generated file. CI verifies
  both the committed payload and its correspondence to that upstream commit.
- Skills, hooks, and the guard remain byte-identical to upstream. Droid supports
  `${CLAUDE_PLUGIN_ROOT}` in the shared launcher, including native packages.
- Keep MCP authentication as browser OAuth at `https://mcp.fly.io`. Never ship
  credentials, tokens, or user-specific account IDs.
- Bump `plugins/fly/.factory-plugin/plugin.json` for published behavior changes.
- Run `python3 scripts/validate.py`, `python3 scripts/test_fly_guard.py`, and
  `python3 -m unittest discover -s tests -v` before pushing.
- Before marketplace submission, verify the source is public, the upstream pin
  is on `superfly/skills` main, and installation works from the pushed commit.
- GitHub PR descriptions and comments must say they were generated by Codex.
  Do not add attribution to commit messages.
