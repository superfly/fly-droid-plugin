# Fly.io for Factory Droid

The installable plugin lives in `plugins/fly`: native Factory manifest,
MCP connection, Fly and brand skills, and confirmation hooks.

- Keep MCP authentication as browser OAuth at `https://mcp.fly.io`. Never ship
  credentials, tokens, or user-specific account IDs.
- Droid expands `${CLAUDE_PLUGIN_ROOT}` in the hook launcher, including native packages.
- Bump `plugins/fly/.factory-plugin/plugin.json` for published behavior changes.
- Run `python3 scripts/validate.py` and `python3 scripts/test_fly_guard.py` before pushing.
- Before marketplace submission, verify public source access and installation
  from the pushed commit.
- GitHub PR descriptions and comments must say they were generated by Codex.
  Do not add attribution to commit messages.
